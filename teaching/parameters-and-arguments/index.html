Parameters vs Arguments

These words show up in almost every function lesson. They are related but not interchangeable.

Parameters Arguments
What Names in the def line — placeholders for incoming values Actual values (or variables) you pass when you call the function
Where Function definition Function call
Python example x and y in def add(x, y): 5 and 3 in add(5, 3)

Summary adapted from GeeksforGeeks: Difference Between Parameters and Arguments. This page is Python-only and matches our course vocabulary.

1 of 5
Parameters

Names in the function header

Parameters are the variable names listed in a def. They tell you how many values the function expects and what each slot is called inside the function body. They do not hold your data until someone calls the function and Python binds arguments to those names.

1
def add(x, y):
2
    return x + y

Here x and y are parameters. They are the same names used in the body on line 2.

2 of 5
Arguments

Values at the call site

Arguments are what you supply when you invoke the function. They can be literals (5), variables (score), or expressions (len(name)). Python evaluates each argument expression first, then passes the results into the parameter slots (see expression evaluation · Rule 4).

1
result = add(5, 3)

5 and 3 are arguments. For this call, Python binds parameter x to 5 and parameter y to 3 while add runs.

3 of 5
Definition + call

Same function, two places

The definition creates the function and lists parameters. A later call passes arguments. The count of positional arguments must match the number of parameters (unless defaults or * syntax apply, which we cover later).

Step through

1
def add(x, y):
2
    return x + y
3
result = add(5, 3)
Starter code: Lines 1–2 define the function; line 3 calls it.
Step 1: On the def line, x and y are parameters — names for values the function will receive.
Step 2: On the call line, 5 and 3 are arguments — the actual values passed into add.
Step 3: While add runs, x is bound to 5 and y to 3. The function returns 8, stored in result.

Quick check

1. In def greet(name):, what is name?

Correct — name is part of the function definition, so it is a parameter.
Not quite. Arguments appear at the call, e.g. greet("Sam").

2. In add(5, 3), what are 5 and 3?

Correct — they are values passed at the call site, so they are arguments.
Parameters are the names in def add(x, y):. Literals in the call are arguments.
