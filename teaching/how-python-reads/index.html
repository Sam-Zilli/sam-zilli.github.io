Python Evaluation Order

How Python Evaluates Expressions

This lesson is about when Python runs each piece of code.

Key Rules · Rule 1

Rule 1

Programs run top to bottom

In a script, Python runs one line at a time, starting at the top and moving down. A line does not begin until the line above it has finished. Later rules in this lesson describe what happens inside a single line; this rule is about the order of the lines themselves.

Visualization

1
age = 23
2
print("Hi", str(age))
Starter code: Two lines in order. Click the steps to see which line Python runs first.
Step 1: Python runs line 1 and stores the integer 23 in age. Line 2 waits.
Step 2: Line 1 is done, so Python moves to line 2 and runs the print call (using the age that already exists).

Key Rules · Rule 2

Rule 2

Use parentheses for math order

If you care which operation happens first, write it in your code with parentheses. That keeps your intent clear to Python and to anyone reading your program. You do not need to memorize PEMDAS like rules for this course.

Visualization

1
total = (price + tax) * quantity → 30
Starter code: The expression as written. Parentheses show which part you want evaluated first.
Step 1: Parentheses say “do this part first.” Python evaluates (price + tax) before the multiply.
Step 2: Inside the group, price + tax becomes 15 (e.g. 10 + 5).
Step 3: Then 15 * quantity runs (e.g. × 2 → 30). Without parentheses, you might not get the order you intend.

Key Rules · Rule 3

Rule 3

Assignment evaluates the RIGHT HAND SIDE first

Python finishes the entire expression on the right of =, then attaches that value to the name on the left. The left side is just the label; it does not run first.

Visualization

1
x = 5 + 7 x = 12
Starter code: The assignment as written. Click the next steps to see what Python evaluates first.
Step 1: Python evaluates 5 + 7 on the right. x on the left waits.
Step 2: The RHS is done. Python binds x to 12, so the line reads x = 12.

Key Rules · Rule 4

Rule 4

Arguments before the function runs

Every argument must be evaluated before the function is called. Positional arguments go left to right. Inner expressions (like an int variable inside a nested call) resolve before the outer call.

Example: print("Hi", str(age))

print needs text, so the second argument uses str(age) to turn the int into a string before the call runs.

1
age = 23
2
print("Hi", str(age))
Starter code: First age is set to the integer 23. Then the print line runs. Click the steps to see how Python prepares each argument.
Step 1: First argument: the string "Hi".
Step 2: For the second argument, Python looks up age and gets the integer 23.
Step 3: str(23) converts the int to the string "23" for print.
Step 4: Both arguments are ready ("Hi" and "23"), so print(...) runs.

Nested function calls

Inside out

One call inside another

When a function call appears inside another call (usually as an argument), Python still follows Rule 4: every argument must become a value before the outer function runs. For nested calls, work from the inside out: evaluate the innermost expression first, run the inner function, then use that result for the next layer outward. The same idea applies to longer chains like max(len(text), 3): finish len(text), then call max with that number.

Visualization: print(str(5 + 7))

print cannot run until its argument is ready. That argument is another call, so Python evaluates 5 + 7 before str, and only then calls print.

1
print(str(5 + 7))
Starter code: Two function calls nested. Click through to see which piece Python evaluates first.
Step 1: Innermost first: Python evaluates 5 + 7 to 12. Neither str nor print runs yet.
Step 2: With 12 ready, Python calls str(12) and gets the string "12". That value is the argument for print.
Step 3: The argument is ready, so print("12") runs and displays output.

Example 2: print("My name is: ", str(name))

A function cannot run until every argument is evaluated. Arguments go left to right; nested pieces resolve inside out.

1
print("My name is: ", str(name))
Starter code: The call as written. No argument is highlighted yet.
Step 1: Arguments are evaluated left to right. The first argument is the string "My name is: ".
Step 2: For the second argument, Python must evaluate the inner expression name before str can run.
Step 3: str(...) produces a string from the value stored in name.
Step 4: Both arguments are ready, so print(...) runs and writes output. The call returns None.
